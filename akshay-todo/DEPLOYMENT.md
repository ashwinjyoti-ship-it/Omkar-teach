# Cloudflare Pages Auto-Deploy (GitHub Actions)

This repo now includes a workflow at:

- `.github/workflows/cloudflare-pages-akshay-todo.yml`

## What it does

On every push to `main` or `work` that changes files in `akshay-todo/**`, GitHub Actions will:

1. Install dependencies (`npm ci`)
2. Build (`npm run build`)
3. Deploy `akshay-todo/dist` to Cloudflare Pages using Wrangler

## One-time setup in GitHub

In your GitHub repository settings:

1. Go to **Settings → Secrets and variables → Actions**.
2. Add these repository secrets:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`

### Token permissions (recommended minimum)

For `CLOUDFLARE_API_TOKEN`, grant:

- **Account → Cloudflare Pages: Edit**
- **Account → Account Settings: Read**

Scope it to the specific Cloudflare account that owns `akshay-todo.pages.dev`.

## Verify deployment

1. Push to `main` (or `work`).
2. Open the **Actions** tab in GitHub and watch the workflow run.
3. After success, check:
   - Production/custom branch URL: `https://akshay-todo.pages.dev`
   - Preview URL shown in workflow logs (if generated by Cloudflare for the deploy)
